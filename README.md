# Messenger MVP — CodeSandbox + Next.js + Supabase

Первая рабочая версия мессенджера:

- регистрация по email/password;
- вход/выход;
- автоматический профиль пользователя;
- список других пользователей;
- личный чат;
- отправка сообщений;
- сообщения в реальном времени через Supabase Realtime;
- RLS для защиты переписки;
- адаптивный интерфейс.

## 1. Создайте проект Supabase

В Supabase создайте новый проект.

Затем откройте:

SQL Editor -> New query

Скопируйте туда весь файл:

supabase/database.sql

и выполните Run.

## 2. Получите ключи Supabase

Откройте настройки проекта/API и возьмите:

- Project URL
- Publishable key

Не используйте service_role key в браузере.

## 3. Добавьте переменные окружения

Создайте `.env.local`:

NEXT_PUBLIC_SUPABASE_URL=https://ВАШ-ПРОЕКТ.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=ВАШ_PUBLISHABLE_KEY

В CodeSandbox эти значения можно добавить в Secrets / Environment Variables.

## 4. Запуск

npm install
npm run dev

## 5. Проверка

1. Зарегистрируйте первый аккаунт.
2. Выйдите.
3. Зарегистрируйте второй аккаунт.
4. Откройте приложение в двух браузерах/окнах.
5. Войдите под разными аккаунтами.
6. Выберите второго пользователя.
7. Отправьте сообщение.

Сообщение должно появиться у второго пользователя без перезагрузки страницы.

## Если после регистрации не входит сразу

Supabase может требовать подтверждение email.

Для тестового MVP можно:
- подтвердить адрес через письмо;
- либо временно отключить обязательное подтверждение email в настройках Auth проекта.

Для публичного приложения подтверждение email лучше оставить включённым.
